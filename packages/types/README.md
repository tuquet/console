# @tuquet/types

Shared utility types for multiple apps, inheriting all capabilities from `@tuquet-core/typings`. Common type definitions can be placed here.

## Usage

### Add Dependency

```bash
# Navigate to target app directory, e.g. apps/xxxx-app
# cd apps/xxxx-app
pnpm add @tuquet/types
```

### Usage

```ts
// Prefer using `import type`
import type { SelectOption } from '@tuquet/types';
```
