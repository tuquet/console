# @vben/types

Shared utility types for multiple apps, inheriting all capabilities from `@vben-core/typings`. Common type definitions can be placed here.

## Usage

### Add Dependency

```bash
# Navigate to target app directory, e.g. apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/types
```

### Usage

```ts
// Prefer using `import type`
import type { SelectOption } from '@vben/types';
```
