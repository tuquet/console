# @tuquet/constants

Shared constants for multiple apps, inheriting all capabilities from `@tuquet-core/shared/constants`. Common business constants can be placed here.

## Usage

### Add Dependency

```bash
# Navigate to target app directory, e.g. apps/xxxx-app
# cd apps/xxxx-app
pnpm add @tuquet/constants
```

### Usage

```ts
import { LOGIN_PATH } from '@tuquet/constants';
```
