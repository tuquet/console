# @vben/styles

Shared style files for multiple apps, inheriting all capabilities from `@vben-core/design`. Common style files can be placed here.

## Usage

### Add Dependency

```bash
# Navigate to target app directory, e.g. apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/styles
```

### Usage

```ts
import '@vben/styles';
```
