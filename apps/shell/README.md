# @operon/shell

Host web console and Tauri desktop shell. Owns auth, session, layouts, top-level routing, access guards, desktop adapters (`src/adapter/desktop`), and the `@operon/kernel` runtime.

```sh
pnpm dev:shell     # Web (port 5320)
pnpm dev:desktop   # Tauri desktop
```

See [Architecture](../../docs/ARCHITECTURE.md) and [Development](../../docs/DEVELOPMENT.md).
